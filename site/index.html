How this page works

  1. The updater reads air temperature, relative humidity, wind speed, and the observation time from the Oxford Physics roof station's current-weather page.
  2. It passes those measurements to Neural-UTCI to calculate UTCI.
  3. It passes the same station measurements to pythermalcomfort to calculate the polynomial UTCI approximation.
  4. Mean radiant temperature (MRT) is assumed to equal air temperature. It is an assumption, not a separate station measurement.
  5. Wind speed is passed through as the station reports it; no adjustment to the model's documented 10 m wind reference is applied.
  6. The latest calculation and its inputs are refreshed daily around midday Oxford time. One snapshot is added to the history each day; older snapshots beyond seven days are removed.

Model input limits

Neural-UTCI accepts air temperature from −50 to 50 °C, MRT from −80 to 120 °C, wind speed from 0.5 to 30.3 m/s, and relative humidity from 5 to 100%. The model is called with its documented oob="clamp" option: values outside those ranges are limited to the nearest accepted value for the calculation. The tables show both the original station reading and the value used by the model, so any adjustment is visible.

The polynomial calculation uses the original station inputs without clamping and pythermalcomfort's input limits. Its documented valid ranges include air temperature from −50 to 50 °C, wind speed from 0.5 to 17 m/s, and relative humidity from 0 to 100%. If an input is outside the polynomial model's valid range, the polynomial result is shown as unavailable; the Neural-UTCI result is still shown using its own documented clamping behavior.

The station notes that its humidity sensor can briefly report 0% in saturated conditions; those readings are shown as reported and clamped to the model's 5% minimum when calculating UTCI.

Source: Oxford Physics roof weather station. UTCI is an estimate based on the stated inputs and MRT assumption.
